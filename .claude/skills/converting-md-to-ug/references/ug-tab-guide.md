# Ultimate Guitar Tablature Guide

Only the section related to tab formatting is included in this guide, copied as-is from the official one.

## 2. Tab formatting rules

### 2.1. Keep it clear

#### A. Additional information

The main goal of creating a tab is to make it clear, correct and easy to read. There must not be any unnecessary additions that distract or complicate the learning process.

**Correct**

```
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------|
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|
```

> No distractions, just the tab.

**Incorrect**

```
    _.-~ /   \___  ______ __  _    _     _   /___| ~-._
    \ /  -~||  __||_  __//  || |  | |  /| | / __/| .\ /
     / . . ||  __| | |\ / ' || |__| |_/ | || (_/ |   \
    / / ~| ||____| |_| /_/|_||____|____||_| \___\| |\ \
   / /   |-~\    \ \ \ | || ||    |    // / /   /~-| \ \
  / /__ / \  \____\|\_\|_/|_||____|___//_/\/___/  / __\ \
 /  .-~\   \-~                                 ~-/\/~-.  \
/.-~    \                                         /    ~-.\
/~      .-                                         -.      ~\
\    .-~                                             ~-.    /
\.-~                                                   ~-./
```

> ASCII-graphics and text distract away from the tab.

#### B. Author’s Notes

Author’s notes are allowed only if they help to understand how to play the song or directly related to the song. Any notes that don't relate to the song or don't explain how to play the song, are not allowed. Author’s notes are better to be placed in brackets in order to be separated from the main text.

**Correct**

```
(Use flanger this measure
to obtain original sound)
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------|
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|
(Watch 2:02 to understand original picking).
```

> Author's note explains how to play a certain part of the song. The notes are placed in brackets

**Incorrect**

```
This is my first tab, please, rate!
```

> Irrelevant comment

### 2.2. Correct formatting

#### A. Number of strings

Tab should contain as many lines as strings on the instrument. (For example, 7 lines for a 7 string guitar).

**Correct**

```
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------|
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|
```

> 6 lines (for 6-string guitar)

**Incorrect**

```
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
```

> Not enough lines

#### B. String sequence

The top line represents the thinnest string and the bottom line represents the thickest string

**Correct**

```
e|-------------------------|-------------------------|
B|-------------------------|-------------------------|
G|-------------------------|-------------------------|
D|-------------------------|-------------------------|
A|-------------------------|-------------------------|
E|---0--1--2--3------------|-------------------------|
```

> Lines are placed in correct order

**Incorrect**

```
E|---0--1--2--3------------|-------------------------|
A|-------------------------|-------------------------|
D|-------------------------|-------------------------|
G|-------------------------|-------------------------|
B|-------------------------|-------------------------|
e|-------------------------|-------------------------|
```

> Lines are placed in reverse order

#### C. Tuning

The guitar tuning field can be found on the left side of each line.

**Correct**

```
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------|
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|
```

> Tuning instructions are specified before the tab lines

**Incorrect**

```
|-------------15----14----|-------------15----14----|
|----15-------------------|----15-------------------|
|-------14-12----14----14-|-------14-12----14----14-|
|-12----------------------|-12----------------------|
|-------------------------|-------------------------|
|-------------------------|-------------------------|
```

> No tuning on the left

#### D. Tab borders

Tab begins and ends with the symbol "|". Please don't use the symbols [ and ] for the tab borders and inside the tab lines.

**Correct**

```
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------|
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|
```

> The lines are the same length. Tab begins and ends with the "|" symbol

**Incorrect**

```
e|-------------15----14----|-------------15----14-----------
B|----15-------------------|----15--------------------
G|-------14-12----14----14-|-------14-12----14----14----
D|-12----------------------|-12-----------------------
A|-------------------------|-------------------------------
E|-------------------------|----------------------
```

> Tab isn’t closed and lines are different length

### 2.3. Representing notes

Numbers indicate the fretted string. Zero means the string is not fretted. Numbers are to be separated with at least one hyphen.

**Correct**

```
e|-------------------------|-------------------------|
B|-------------------------|-------------------------|
G|-------------------------|-------------------------|
D|-------------------------|-------------------------|
A|-------------------------|-------------------------|
E|---0--1--2--3------------|-------------------------|
```

> The notes are separated with a hyphen

**Incorrect**

```
e|-------------------------|-------------------------|
B|-------------------------|-------------------------|
G|-------------------------|-------------------------|
D|-------------------------|-------------------------|
A|-------------------------|-------------------------|
E|---0123------------------|-------------------------|
```

> No hyphen between the notes

### 2.4. Parts

#### A. Song parts

A tab needs to be fully completed. Parts of a song (intro, chorus, verse, solo etc) need to be marked. If a song is not divided into "chorus," "verse" - you don't have to indicate them. The name of the part is put into square brackets: [Intro].

**Correct**

```
[Intro]
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------|
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|

[Verse]
e|------------------------|--------------------------|
B|------------------------|--------------------------|
G|-------0----------------|-------0------------------|
D|----4-----4-----4-----4-|----4-----4-----4-----4---|
A|-2-----------2-----5----|-0-----------0-----5------|
E|------------------------|--------------------------|
```

> Parts of a song are divided into square brackets and are separated from the tab with two enters.

**Incorrect**

```
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------|
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|

e|------------------------|--------------------------|
B|------------------------|--------------------------|
G|-------0----------------|-------0------------------|
D|----4-----4-----4-----4-|----4-----4-----4-----4---|
A|-2-----------2-----5----|-0-----------0-----5------|
E|------------------------|--------------------------|
```

> Parts of a song aren't indicated.

#### B. References to song parts

Do not use references to song parts in the tab, instead, paste the tab of the part itself. This way users won’t have to scroll back and forth through the tab to play it.

**Correct**

```
[Chorus]
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------|
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|

[Verse]
e|------------------------|--------------------------|
B|------------------------|--------------------------|
G|-------0----------------|-------0------------------|
D|----4-----4-----4-----4-|----4-----4-----4-----4---|
A|-2-----------2-----5----|-0-----------0-----5------|
E|------------------------|--------------------------|

[Chorus]
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------|
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|
```

> No references are used.

**Incorrect**

```
[Chorus]
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------|
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|

[Verse]
e|------------------------|--------------------------|
B|------------------------|--------------------------|
G|-------0----------------|-------0------------------|
D|----4-----4-----4-----4-|----4-----4-----4-----4---|
A|-2-----------2-----5----|-0-----------0-----5------|
E|------------------------|--------------------------|

chorus x1
```

> There should be no references to the song parts inside the tab.

#### C. Repeats

When a part of a song is to be played multiple times, the correct number of repetitions must be specified.

**Correct**

```
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------| x2
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|

```

> Repetition number is mentioned on the right.

**Incorrect**

```
e|-------------15----14----|-------------15----14----|
B|----15-------------------|----15-------------------|
G|-------14-12----14----14-|-------14-12----14----14-|
D|-12----------------------|-12----------------------|
A|-------------------------|-------------------------|
E|-------------------------|-------------------------|
repeat as necessary
```

> The exact repetition number is not specified.

#### A. Tab legend

[List of symbols]

#### B. Using the notations

The legend is to be placed after the tab and contains only the effects that were used in the tab.

"Dead note" is represented with an "x" and should be placed instead of a note.

"Vibrato" is represented with an "~" and should be placed after the note during vibrato continuance.

"Slide" is represented with an "/" and should be placed between the starting and the ending note, with no symbols in the middle.

The rest of the legend notations should be placed after the note, except for special symbols that are specified above and placed under the note.

If you use any symbol that is not specified in the original legend, the symbol and its explanation should be put in the legend. Please, try to use original symbols of the legend, using custom symbols only as an exception.

Don't use the “<” and “>” symbols in a row, like this “<>”, as the content between these symbols shall be deleted due to possible fraud html usage.

**Correct**

```
e|--------------------5-5-5-|----------------------|
B|--------------------5-5-5-|----------------------|
G|--------------------4-4-4-|----------------------|
D|-----------2-4pb----4-4-4-|-4--2-----------------|
A|--0--2/4------------------|-------4--2~~~--------|
E|--------------------------|----------------------|

***********************************

| /   Slide-up
| pb  Pre-bend
| ~   Vibrato

***********************************
```

> The legend shows only the effects that are used in the tab. All effects in the tab are used correctly

**Incorrect**

```
e|--------------------5-5-5-|----------------------|
B|--------------------5-5-5-|----------------------|
G|--------------------4-4-4-|----------------------|
D|-----------2-pb4----4-4-4-|-4--2-----------------|
A|--0--2-/-4----------------|-------4--2~----------|
E|--------------------------|----------------------|

***********************************
| /   Slide up
| \   Slide down
| h   Hammer-on
| p   Pull-off
| ~   Vibrato
| +   Harmonic
| x   Dead note
| b   Bend
| pb  Pre-bend
| br  Bend release
| pbr Pre-bend release
| brb Bend release bend
***********************************
```

> The symbols that are not used in the tab are specified in the legend. Slide, pre-bend and vibrato symbols are not used correctly.
